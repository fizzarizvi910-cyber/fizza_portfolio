# Personal Portfolio Website

## Project Title
Personal Portfolio Website

## About the Project
This is my personal portfolio website created as part of my web development internship. 
The website presents my introduction, technical skills, projects, and contact information 
in a clean and responsive design.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Features
- Responsive design for desktop and mobile devices
- About Me section
- Skills section
- Projects section
- Contact section
- Simple and clean user interface

## Setup Instructions

1. Clone the repository:
   git clone https://github.com/fizzarizvi910-cyber/fizza_portfolio.git

2. Open the project folder.

3. Open `index.html` in a web browser.

No additional dependencies are required.
